# Contribuer — corriger une fiche

Une correction = une issue sur ce dépôt (**issue**) ou une **pull request** sur la fiche concernée.

Ce qui est accepté : un fait daté avec sa **source citée** (document, page officielle, article, témoignage identifié),
une erreur de classement argumentée, une entrée nouvelle qui respecte le périmètre du corpus (voir le README).
Ce qui ne l'est pas : une appréciation sans source, un changement de périmètre hors décision explicite.

Délai de réponse : **un mois**. Toute contribution acceptée est publiée sous les licences du dépôt (`LICENSE`) ;
les contributeurs sont nommés dans la fiche s'ils le souhaitent.
